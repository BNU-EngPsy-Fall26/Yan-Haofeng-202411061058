# 智驾夜间行人检测 · SDT 交互式实验网站

工程心理学课程作业。项目使用 **HTML + CSS + JavaScript** 实现一个基于信号检测论（Signal Detection Theory, SDT）的交互式实验网站，以“智能驾驶夜间行人检测”为应用场景。

网站包含完整的检测游戏、SDT 结果统计、交互式概念实验室和多局数据对比。项目为纯前端实现，无需安装 Python、Node.js 或其他依赖。

## 运行方式

1. 下载或 clone 本仓库。
2. 双击根目录中的 `index.html`。
3. 使用 Chrome、Edge 等现代浏览器打开即可运行。

> 核心功能不依赖服务器，助教 clone 后可直接运行。

## 实验场景与参数

- **Signal（信号）**：前方存在需要紧急响应的行人。
- **Noise（噪声）**：前方不存在行人，仅存在路牌、立柱、树影、护栏等视觉杂波。
- 每局 **30 个试次**，其中 15 个 Signal、15 个 Noise，`P(S)=0.50`。
- 每个道路刺激呈现 **1000 ms**。
- 系统设定 `d′` 可调，用于改变刺激的视觉可分辨性。
- 低 `d′` 条件下会增加目标模糊、低对比、部分遮挡、类人干扰物相似度和候选物数量；高 `d′` 条件下这些干扰减弱。

## 操作方式

进入实验后会先出现键位说明页：

- `F`：**紧急制动**，表示判断“有行人”。
- `J`：**继续行驶**，表示判断“无行人”。
- `Space`：双手就位后**开始实验**。

道路刺激显示期间提前按 `F` / `J` 不会被记录；刺激消失后进入正式作答阶段。页面按钮保留为鼠标备用操作。

## 四种 SDT 结果

| 实际状态 | 用户判断 | SDT 结果 | 场景含义 |
|---|---|---|---|
| 有行人 | 紧急制动 | Hit (H) | 成功发现行人并制动 |
| 有行人 | 继续行驶 | Miss (M) | 漏报行人风险 |
| 无行人 | 紧急制动 | False Alarm (FA) | 发生不必要制动 |
| 无行人 | 继续行驶 | Correct Rejection (CR) | 正确判断道路安全 |

## 自动统计与计算

每局结束后，网站自动统计并展示：

- `H / M / FA / CR`
- 击中率 `P(Hit)`
- 误报率 `P(FA)`
- 实测敏感性 `d′`
- 判定标准 `c`
- 准确率 `Accuracy`
- 系统设定 `d′` 与实测 `d′` 的对比

核心公式：

```text
P(Hit) = H / (H + M)
P(FA)  = FA / (FA + CR)

d′ = Z[P(Hit)] - Z[P(FA)]

c = -0.5 × { Z[P(Hit)] + Z[P(FA)] }

Accuracy = (H + CR) / (H + M + FA + CR)
```

当 `P(Hit)` 或 `P(FA)` 恰好等于 0 或 1 时，直接进行 Z 变换会得到无穷值。因此程序仅在这种极端情况下对用于 Z 变换的比例进行边界修正；页面仍显示真实的原始击中率和误报率。

## 概念实验室

网站提供独立的“概念实验室”，用于交互式理解 SDT 核心概念。

### 1. 两个分布

- 拖动 `d′`，观察 Signal / Noise 两个正态分布如何靠近或分离。
- 拖动判定标准 `c`，观察 criterion 位置变化。
- 实时联动显示 H、M、FA、CR 概率、β、AUC 和混淆矩阵。
- 图中使用半透明区域表现四种结果对应的概率区域。

### 2. ROC 曲线

- 拖动 `c`，观察当前操作点沿同一条 ROC 曲线移动。
- 改变 `d′`，观察整条 ROC 曲线发生变化。
- 实时显示 `P(Hit)`、`P(FA)` 与 AUC。

### 3. 标准与奖惩

- 调节信号先验概率 `P(S)`。
- 使用完整支付矩阵设置 Hit 收益、Miss 代价、FA 代价和 CR 收益。
- 四个支付参数同时支持**滑块拖动**和**数字精确输入**。
- 自动计算最优 `β` 和最优 `c`，并解释当前策略偏宽松还是偏保守。

## 多局数据对比

每完成一局，网站会记录该局的：

- 系统设定 `d′`
- 实测 `d′`
- 判定标准 `c`
- 准确率
- `P(Hit)` 与 `P(FA)`

结果页提供多局历史表格和“系统设定 `d′` vs 实测 `d′`”折线对比。历史数据优先保存在浏览器 `localStorage` 中；若浏览器在 `file://` 环境下限制本地存储，当前页面会话仍可正常使用。

## 文件结构

```text
sdt-autodrive-lab/
├─ index.html          # 网站页面结构
├─ style.css           # 全站视觉样式与响应式布局
├─ README.md           # 项目说明与运行方法
└─ js/
   ├─ sdt.js           # SDT 数学、正态分布与指标计算
   ├─ game.js          # 游戏流程、Canvas 刺激、结果统计与历史记录
   ├─ lab.js           # 概念实验室、双分布、ROC 与奖惩可视化
   └─ app.js           # 页面切换、键盘/鼠标事件与控件绑定
```

## 代码组织说明

代码按职责拆分，避免将所有逻辑集中在单个脚本中：

- `sdt.js` 只处理数学与 SDT 指标。
- `game.js` 只处理实验任务、刺激生成和结果记录。
- `lab.js` 只处理概念实验室及其可视化。
- `app.js` 负责页面之间的连接和事件绑定。
- `style.css` 按首页、游戏、结果页、概念实验室、指导语等区域分段，并在关键模块处添加注释。

## 技术说明

- 原生 HTML5 / CSS3 / JavaScript。
- Canvas API 用于生成夜间道路刺激、双分布图、ROC 曲线和多局对比图。
- 不使用前端框架，不依赖外部 CDN。
- 不需要 Flask 或数据库，双击 `index.html` 即可运行。
